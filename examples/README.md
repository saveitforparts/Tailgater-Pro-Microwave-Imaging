**Example Files**

Data files output by dtp_scan.py, for processing with dtp_image.py

This example data is from a South-centered scan from 120° to 240° azimuth, 15° to 55°
elevation, located in St. Paul, Minnesota (approximately Latitude 45°N, Longitude 93°W)

- "raw-data-20261122-154313.txt":   numpy matrix of signal strength at each azimuth and elevation pair

- "scan-settings-20261122-154313.txt":    scan parameters for dtp_image to use when processing

- "result-20261122-154313.png":     Preview image created by dtp_scan (not used by dtp_image)
